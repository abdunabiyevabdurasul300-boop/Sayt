DONUZ — Telegram bot + sayt (umumiy PostgreSQL)

MUHIM: Bu paket kod bazasi. Uni o‘zingizning Render va API sozlamalaringiz bilan joylashtirish kerak; bu muhitdan Telegram/Render hisobingizga kira olmayman.

1. ZIP ichidagi donuz_dual_service papkasidagi fayllarni GitHub repozitoriyingiz ildiziga yuklang (bot.py, web_server.py, requirements.txt, static/). Avval mavjud fayllarning zaxira nusxasini oling.
2. Render’da PostgreSQL yarating. Uning Internal Database URL qiymatini nusxalang.
3. Telegram bot uchun alohida Background Worker yoki Web Service yarating: Build Command: pip install -r requirements.txt; Start Command: python bot.py.
4. Sayt/API uchun alohida Web Service yarating: Build Command: pip install -r requirements.txt; Start Command: python web_server.py.
5. IKKALA servisga bir xil DATABASE_URL kiriting. Faqat bot servisida BOT_TOKEN va ADMIN_ID shart; sayt API kod yuborishi uchun unga ham BOT_TOKEN kerak. bot.py talab qiladigan BAY2GAME_API_KEY va boshqa API/karta ENV qiymatlarini ham tegishli servislarga kiriting. Kalitlarni kod ichiga yozmang.
6. Sayt o‘zining Web Service domenidan /api/... endpointlariga murojaat qiladi; static/script.js ichida relative URL ishlatiladi.
7. Web Service URL ni ochib /health ni tekshiring. So‘ng Telegram’da /start va inline tugmalarni tekshiring.

UMUMIY BALANS: Bot va sayt bir xil PostgreSQL DATABASE_URL ishlatishi shart. Alohida DB bo‘lsa balanslar sinxron bo‘lmaydi.

Eslatma: Eski bot bazasini avtomatik o‘chirib yubormang yoki almashtirmang. Eski foydalanuvchi/balans ma’lumotlarini yangi PostgreSQL’ga ko‘chirish zarur bo‘lsa, avval zaxira olib migratsiya qiling. Paket sintaksis jihatidan tekshirilishi mumkin, ammo haqiqiy Render, PostgreSQL va Bay2Game API kalitlari bilan jonli buyurtma testi sizning hisobingizda bajarilishi kerak.
