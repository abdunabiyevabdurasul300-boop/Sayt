DONUZ BOT + WEB API — Render sozlamasi

1) Ikkala servis ham aynan bir xil PostgreSQL DATABASE_URL ishlatsin.
   SQLite bot.db ishlatmang: alohida Render servislarida umumiy balans bo'lmaydi.

2) Telegram bot servisi:
   Build Command: pip install -r requirements.txt
   Start Command: python bot.py
   Environment: RUN_MODE=bot
   Shuningdek botda hozir talab qilinadigan barcha ENV qiymatlari bo'lishi shart:
   BOT_TOKEN, ADMIN_ID, BAY2GAME_API_KEY, DATABASE_URL,
   BOT_TOKEN_ENCRYPTION_KEY (agar ishlatayotgan bo'lsangiz), va qolgan API/karta sozlamalari.

3) Web API uchun alohida Render Web Service yarating (shu repo/fayllar):
   Build Command: pip install -r requirements.txt
   Start Command: python web_server.py
   Environment: DATABASE_URL va Web API ishlatadigan bir xil BOT_TOKEN,
   BAY2GAME_API_KEY hamda bot kodidagi kerakli boshqa ENV qiymatlari.
   PORT ni Render o'zi beradi; qo'lda kiritish shart emas.

4) Sayt frontendidagi API manzilini yangi Web Service URL ga o'zgartiring.
   Web API health tekshiruvi: https://SIZNING-WEB-SERVIS.onrender.com/health

5) Muhim: bu ajratish bot polling va web API jarayonlarini mustaqil qiladi.
   Har ikkisi bir xil PostgreSQL users jadvalidagi balansni o'qiydi.
   Biroq botdagi ayrim eski xarid oqimlari balansni tekshirish va yechishni
   alohida qilishi mumkin; real parallel xaridlar uchun ularni ham atomik
   yechishga o'tkazish va frontend CORS ni domen bilan cheklash kerak.
